# Insurance Amount Prediction using Linear Regression

This project focuses on predicting insurance charges based on demographic and health-related attributes.  
The analysis applies machine learning techniques to identify key factors affecting insurance premiums and to build a regression model capable of accurate cost estimation.

---

## 🔍 Project Overview

The goal of this project is to:
- Develop a **Linear Regression model** to estimate insurance charges.
- Explore and visualize the dataset to understand relationships among variables.
- Evaluate model performance using multiple regression metrics.
- Gain insights into how factors such as **smoking** and **BMI** influence insurance cost.

---

## 📌 Key Steps Performed

✔ **Data Exploration & Visualization**
- Plotted variable relationships and distributions  
- Used **Matplotlib, Seaborn, and Plotly** to identify meaningful patterns

✔ **Data Preprocessing**
- Handled missing values
- Encoded categorical variables (e.g., sex, smoker, region)

✔ **Model Building**
- Implemented **Linear Regression** using Scikit-learn

✔ **Model Evaluation**
- Assessed performance using:
  - **R² Score**
  - **Mean Absolute Error (MAE)**
  - **Root Mean Squared Error (RMSE)**

✔ **Insights**
- Smoking and BMI were found to significantly increase insurance premiums
